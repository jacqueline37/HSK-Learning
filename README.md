# HSK-Learning

新HSK（HSK 3.0）1級・2級のリスニング・リーディング・書写対策ができる、ブラウザだけで動く練習サイトです。
語彙と出題形式は、中外语言交流合作中心の「HSK考试大纲」（2025年11月発表・2026年7月施行）と公式の样卷（サンプル問題）に合わせています。
PC・スマホ・タブレットに対応しています。ビルドやサーバー側の処理は不要です。

画面上部の「1級／2級」で級を切り替えます（選んだ級は保存されます）。

## できること

### 1級（300語・40問）

- 🎧 リスニング（听力）
  1. 絵を選ぶ … 文を聞いて、合う絵を選ぶ
  2. 応答を選ぶ … 問いかけを聞いて、合う答えを選ぶ
  3. 会話と絵 … 短い会話を聞いて、合う絵を選ぶ
  4. 質問に答える … 文と質問（问）を聞いて、答えを選ぶ
- 📖 リーディング（阅读）
  1. 文と絵 … 文を読んで、合う絵を選ぶ
  2. 問いと答え … 問いに合う答えを選ぶ
  3. 空欄補充 … 空欄に入る語を選ぶ
  4. 短文と問い … 短い文を読んで、★の問いに答える

### 2級（新出200語、1級と合わせて500語・60問）

- 🎧 リスニング（听力）
  1. 絵を選ぶ … 文を聞いて、合う絵を選ぶ
  2. 会話と絵 … 短い会話を聞いて、合う絵を選ぶ
  3. 会話と質問 … 会話と質問（问）を聞いて、答えを選ぶ
- 📖 リーディング（阅读）
  1. 文と絵 … 文を読んで、合う絵を選ぶ
  2. 空欄補充 … 空欄に入る語を選ぶ
  3. 文と応答 … 文に合う応答を選ぶ
  4. 短文と問い … 短い文を読んで、★の問いに答える
- ✍️ 書写（书写）
  1. 漢字の部分 … 語の意味とピンインを手がかりに、漢字の欠けている部分（部首など）を選ぶ
  2. 漢字を書く … ピンインを見て、（　）に入る漢字を選ぶ（本番は手書き）

### 共通

- **練習問題**：各部分10問。答えるたびに解説（ピンイン・日本語訳）が出ます
- **模擬試験**：公式样卷と同じ問題数（1級40問・2級60問）。音声は本番同様2回ずつ流れ、解答は最後にまとめて表示。
  配点は公式の発表がないため、各セクション100点・合計の6割を合格の目安にしています
- **単語ドリル**：単語と絵が合っているか ✓／✗ で答える（旧HSK1級の形式を残したもの）
- **復習**：間違えた問題が級ごとに自動でたまり、あとからまとめて解き直せる
- **単語帳**：その級の語を漢字・ピンイン・日本語で検索、タップで発音を確認。日本語訳・ピンインの表示切り替えあり
- **例文テーマ**：アークナイツ（明日方舟）のキャラクターが登場する例文を収録。設定で「ふつう＋アークナイツ／ふつうのみ／アークナイツのみ」を切り替え
- **設定**：例文テーマ、ピンイン表示、読み上げ速度（0.5〜1.2）、練習でも2回ずつ流すか、学習記録のリセット

ベストスコア・復習リスト・設定はブラウザの `localStorage` に保存されます（端末ごと）。
旧HSK1級版の記録は、初回表示時に1級の対応する部分へ引き継がれます。

## 音声について

音声は Microsoft Edge TTS（女性：Xiaoxiao／男性：Yunxi）で事前に生成した MP3 を `audio/` に収録しています。
収録音声がない文は、ブラウザの読み上げ機能（Web Speech API）で代わりに再生します。

問題データ（`js/data.js`・`js/data2.js`）を変更したら、音声を作り直してください。

```powershell
pip install edge-tts
```

```powershell
python tools/make_audio.py
```

- Python と Node.js が必要です（`tools/extract.js` でデータから読み上げる文を抜き出します）
- 既存のファイルはスキップし、足りない音声だけを生成します
- `js/audio-map.js`（文 → ファイルの対応表）は自動生成されるので、手で編集しないでください
- 音声は速度 -15% で収録しており、アプリの速度設定 0.8 がこの等速にあたります

## 問題を追加するとき

復習リストは「部分＋問題の番号」で問題を覚えているので、各配列への追加は必ず**末尾**に行ってください（途中に入れると番号がずれます）。

## ファイル構成

```
index.html          ページ本体
css/style.css       スタイル
js/data.js          1級：語彙300語と問題データ
js/data2.js         2級：語彙200語と問題データ
js/app.js           画面・出題・採点・音声再生のロジック
js/audio-map.js     音声ファイルの対応表（自動生成）
audio/              収録済み音声（MP3）
tools/make_audio.py 音声生成スクリプト
tools/extract.js    data.js・data2.js から読み上げる文を抜き出す補助スクリプト
tools/ogp.html      OGP画像（ogp.png）の元
favicon.svg         アイコン
```
