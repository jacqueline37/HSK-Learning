# HSK-Learning

旧HSK1級（150語）のリスニング・リーディング対策ができる、ブラウザだけで動く練習サイトです。
PC・スマホ・タブレットに対応しています。ビルドやサーバー側の処理は不要です。

## できること

- **練習問題**：本番の出題形式に沿った8つのパート（各10問）
  - 🎧 リスニング（听力）
    1. 判断（単語）… 単語を聞き、絵と合っていれば ✓、違えば ✗
    2. 絵を選ぶ（文）… 文を聞いて、合う絵を選ぶ
    3. 会話と絵 … 短い会話を聞いて、合う絵を選ぶ
    4. 質問に答える … 文と質問（问）を聞いて、答えを選ぶ
  - 📖 リーディング（阅读）
    1. 判断（単語）… 単語と絵が合っているか判断
    2. 文と絵 … 文を読んで、合う絵を選ぶ
    3. 問いと答え … 問いに合う答えを選ぶ
    4. 空欄補充 … 空欄に入る語を選ぶ
- **模擬試験**：リスニング20問＋リーディング20問、200点満点（120点で合格）。音声は本番同様2回ずつ流れ、解答は最後にまとめて表示
- **復習**：間違えた問題が自動でたまり、あとからまとめて解き直せる
- **単語帳**：150語を漢字・ピンイン・日本語で検索、タップで発音を確認。日本語訳・ピンインの表示切り替えあり
- **例文テーマ**：アークナイツ（明日方舟）のキャラクターが登場する例文（各部分12問）を収録。設定で「ふつう＋アークナイツ／ふつうのみ／アークナイツのみ」を切り替え
- **設定**：例文テーマ、ピンイン表示、読み上げ速度（0.5〜1.2）、練習でも2回ずつ流すか、学習記録のリセット

ベストスコア・復習リスト・設定はブラウザの `localStorage` に保存されます（端末ごと）。

## 音声について

音声は Microsoft Edge TTS（女性：Xiaoxiao／男性：Yunxi）で事前に生成した MP3 を `audio/` に収録しています。
収録音声がない文は、ブラウザの読み上げ機能（Web Speech API）で代わりに再生します。

問題データ（`js/data.js`）を変更したら、音声を作り直してください。

```powershell
pip install edge-tts
```

```powershell
python tools/make_audio.py
```

- Python と Node.js が必要です（`tools/extract.js` で `data.js` から読み上げる文を抜き出します）
- 既存のファイルはスキップし、足りない音声だけを生成します
- `js/audio-map.js`（文 → ファイルの対応表）は自動生成されるので、手で編集しないでください
- 音声は速度 -15% で収録しており、アプリの速度設定 0.8 がこの等速にあたります

## ファイル構成

```
index.html          ページ本体
css/style.css       スタイル
js/data.js          語彙150語と問題データ
js/app.js           画面・出題・採点・音声再生のロジック
js/audio-map.js     音声ファイルの対応表（自動生成）
audio/              収録済み音声（MP3）
tools/make_audio.py 音声生成スクリプト
tools/extract.js    data.js から読み上げる文を抜き出す補助スクリプト
favicon.svg         アイコン
```
